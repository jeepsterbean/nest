# Phases interface

The Core guide to attention. Derivation and work recording live in
[Phases domain](../domain/phases.md).

## Phases pane

The Phases pane of Core is a read-only guide: how Phase is derived, then the
four Phases (Doing, Scoping, Resting, Offline) with their meanings. Both must
mirror the [Phase derivation](../domain/phases.md#phase-derivation). The current Phase is marked. Its icon is
picked from the Core sidebar.
Phase icons and colors follow
[Phase appearance](time-surfaces.md#phase-appearance).
